# 跨境吴老师 Amazon细分类目进入评分与分级 Skill

面向 Amazon 选品决策：根据商品关键词或明确类目路径，调用使用者环境中的卖家精灵 MCP 定位最相关叶子类目，以 Top100 商品样本月均销量等六项指标计算评分和 S/A/B/C/D 经验等级，交付离线 HTML 看板。关键词搜索结果和 Excel 不是类目取数来源；样本销量不代表全类目销量。

## 运行前准备

- 当前环境可访问本公开 GitHub 仓库，以便每次运行前检查并在需要时更新 Skill 版本。
- 当前环境已配置、授权且可调用卖家精灵／SellerSprite MCP；Skill 会验证实际只读请求，不以工具列表代替连接成功。
- 提供商品关键词或明确的 Amazon 类目路径；站点默认 US，未指定锚点时使用执行当月。

无法核验最新版本、无法更新或无法调用必需 MCP 能力时，Skill 会停止，不会用旧版本、其他数据源或模拟数据出看板。Skill 包不包含 MCP 连接地址或凭据，也不会自动安装 MCP。

## 首次安装

本仓库是公开仓库，无需向跨境吴老师提交 GitHub 用户名、接受私有仓库邀请或提供令牌。在支持 GitHub Skill 导入的平台，将下面整段指令发送给安装助手：

```text
请从 https://github.com/defway888-design/kuajing-wulaoshi-amazon-category-entry-scoring-skill 安装跨境吴老师 Amazon细分类目进入评分与分级 Skill。安装后按当前平台的方式重新加载 Skill。
```

不支持原生 Skill 导入的平台，可按其规则将仓库文件作为一个完整技能包导入；`SKILL.md` 是执行入口，包内相对引用的文件须保留。是否需要登录 GitHub 或重新启动，由安装平台决定。

## 启动方式

```text
使用跨境吴老师 Amazon细分类目进入评分与分级 Skill，分析我输入的商品关键词。
```

也可以直接给出完整类目路径。Skill 先检查远端版本，再检查卖家精灵 MCP 连接；通过后才获取类目数据并生成看板。成功时只交付一个 HTML 文件链接，失败时说明实际阻塞原因。

## 更新与边界

每次运行都实时对比仓库 `main` 分支的 `VERSION`。发现更高版本时，须完整更新并重新加载后才能继续；网络、更新权限或新版文件核验失败时停止。六项评分和等级仅用于经验筛选，不代表盈利概率或直接备货结论。请勿向公开仓库提交密钥、用户输入、真实市场数据或生成的看板。

维护者每次修改 Skill 包内文件时都须递增 `VERSION`，并在下方记录实际变更；不要发布未更新版本号的文件改动。

## 版本更新记录

### v1.2.0｜2026-10-07（北京时间）

- Top100 请求完整返回但实际商品不足100件时，改按实际商品数计算，不再要求证明整个类目商品池不足100；漏页、重复记录和缺失销量仍须核查。
- 看板仅在近30天样本或某个趋势月份不足100件时显示对应的实际商品数；完整100件时不显示额外的商品数量提示。
- 影响范围：候选类目样本比较、第一项均值、月度趋势样本标注和固定看板模板；六项评分公式、阈值与分级规则不变。

### v1.1.0｜2026-10-07（北京时间）

- 第一项改为近30天 Top100 商品样本月均销量，保留 1,500 件/商品/月满分阈值，并增加样本完整性校验。
- 多个候选类目统一按同口径 Top100 样本销量合计比较；区分样本均值与默认前10名头部均值，增加样本数和数据一致性校验。
- 看板第一项名称、来源和样本限制同步更新，删除旧的全类目取数与无关兜底表述；历史看板仅在确认是相同 Top100 样本口径时才可比较。
- 影响范围：类目选择、第一项取数和评分口径、数据校验及固定看板模板；其余五项评分阈值与分级规则不变。

### v1.0.0｜2026-09-29（北京时间）

- 首次封装已确认的类目定位、六项评分、S/A/B/C/D 分级与固定 HTML 看板规则。
- 增加每次运行前的在线版本检查、完整更新要求和卖家精灵 MCP 实际连通性检查。
- 影响范围：业务规则、运行前置条件、交付模板和安装说明。
